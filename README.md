# Эмулятор командной строки

Автор: Варданян Акоб Эдуардович, ИКБО-60-25. Вариант 3.

## Описание

Консольный (CLI) эмулятор оболочки UNIX-подобной ОС на Python.
Текущий этап — VFS: эмулятор загружает виртуальную файловую
систему из ZIP-архива в память.

## Функции

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | заглушка: выводит имя команды и аргументы |
| `exit` | завершает работу эмулятора |

- Приглашение к вводу содержит имя VFS, например `deep$ `.
  Без параметра `--vfs` приглашение — `VFS$ `.
- Ввод разбивается на команду и аргументы по пробелам.
- Пустая строка выводит новое приглашение.
- Неизвестная команда выводит сообщение `Unknown command`.

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs ПУТЬ` | путь к ZIP-архиву с VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

Оба параметра необязательны. При запуске эмулятор выводит
отладочную информацию о всех заданных параметрах:

```
[debug] vfs = deep.zip
[debug] script = scripts/vfs_test.txt
```

Неизвестный параметр приводит к сообщению об ошибке
и завершению программы.

## VFS

Виртуальная файловая система загружается из ZIP-архива,
путь к которому задаётся параметром `--vfs`.

- Архив не распаковывается на диск: структура папок
  и содержимое файлов читаются напрямую и хранятся в памяти.
  Данные VFS не изменяются.
- Текстовые файлы хранятся в виде строк, двоичные —
  в виде строк base64.
- Имя VFS — имя архива без расширения, оно показывается
  в приглашении к вводу.

Ошибки загрузки (эмулятор завершается с кодом 1):

| Ситуация | Сообщение |
|----------|-----------|
| архив не найден | `VFS not found: ПУТЬ` |
| файл не является ZIP-архивом | `invalid VFS format: ПУТЬ` |

### Тестовые VFS

Исходные данные VFS хранятся в репозитории в виде папок,
архивы собираются скриптом (сами архивы в репозиторий
не добавляются):

```
python3 -m src.make_archive
```

| Архив | Папка | Содержимое |
|-------|-------|------------|
| `minimal.zip` | `vfs/minimal` | один файл |
| `multi.zip` | `vfs/multi` | несколько файлов |
| `deep.zip` | `vfs/deep` | 3 уровня вложенности папок и файлов |

## Стартовый скрипт

Текстовый файл, каждая строка которого — команда эмулятора.

- Строки, начинающиеся с `#`, считаются комментариями
  и пропускаются.
- Пустые строки пропускаются.
- Каждая команда выводится вместе с приглашением, затем её
  результат — как при диалоге с пользователем.
- Команда `exit` в скрипте завершает работу эмулятора,
  следующие команды не выполняются.
- После выполнения скрипта (без `exit`) эмулятор переходит
  в интерактивный режим.
- Если файл скрипта не найден, выводится сообщение
  `script not found` и запускается интерактивный режим.

Скрипты лежат в папке `scripts/`:

- `start.txt` — команды, комментарии и неизвестная команда;
- `exit.txt` — проверка завершения по `exit` посередине скрипта;
- `vfs_test.txt` — все команды и режимы для проверки работы с VFS.

## Запуск и тесты

Все команды выполняются из корня проекта.

Запуск эмулятора:

```
python3 -m src.make_archive
./run.sh --vfs deep.zip --script scripts/vfs_test.txt
```

Скрипты ОС лежат в папке `os_scripts/`:

| Скрипт | Что проверяет |
|--------|---------------|
| `test_no_args` | запуск без параметров |
| `test_vfs` | только `--vfs` |
| `test_script` | только `--script` |
| `test_all` | оба параметра |
| `test_bad_script` | несуществующий файл скрипта |
| `test_vfs_minimal` | минимальная VFS |
| `test_vfs_multi` | VFS с несколькими файлами |
| `test_vfs_deep` | VFS с 3 уровнями вложенности |
| `test_vfs_missing` | несуществующий архив VFS |
| `test_vfs_bad_format` | файл, не являющийся ZIP-архивом |

Запуск тестов:

```
python3 -m unittest discover -s tests -v
```

```

deep$ ls -l /level1

```

