# Эмулятор командной строки

Автор: Варданян Акоб Эдуардович, ИКБО-60-25. Вариант 3.

## Описание

Консольный (CLI) эмулятор оболочки UNIX-подобной ОС на Python.
Текущий этап — конфигурация: эмулятор принимает параметры
командной строки и умеет выполнять стартовый скрипт.

## Функции

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [аргументы]` | заглушка: выводит имя команды и аргументы |
| `exit` | завершает работу эмулятора |

- Приглашение к вводу содержит имя VFS: `VFS$ `.
- Ввод разбивается на команду и аргументы по пробелам.
- Пустая строка выводит новое приглашение.
- Неизвестная команда выводит сообщение `Unknown command`.

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs ПУТЬ` | путь к физическому расположению VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

Оба параметра необязательны. При запуске эмулятор выводит
отладочную информацию о всех заданных параметрах:

```
[debug] vfs = myvfs.zip
[debug] script = scripts/start.txt
```

Неизвестный параметр приводит к сообщению об ошибке
и завершению программы.

## Стартовый скрипт

Текстовый файл, каждая строка которого — команда эмулятора.

- Строки, начинающиеся с `#`, считаются комментариями
  и пропускаются.
- Пустые строки пропускаются.
- Каждая команда выводится вместе с приглашением, затем её
  результат — как при диалоге с пользователем.
- Команда `exit` в скрипте завершает работу эмулятора,
  следующие команды не выполняются.
- После выполнения скрипта (без `exit`) эмулятор переходит
  в интерактивный режим.
- Если файл скрипта не найден, выводится сообщение
  `script not found` и запускается интерактивный режим.

Примеры скриптов лежат в папке `scripts/`:

- `start.txt` — команды, комментарии и неизвестная команда;
- `exit.txt` — проверка завершения по `exit` посередине скрипта.

## Запуск и тесты

Запуск эмулятора (из корня проекта):

```
./run.sh
python3 -m src.main --vfs myvfs.zip --script scripts/start.txt
```

Скрипты ОС для проверки всех параметров лежат в папке
`os_scripts/` и запускаются из корня проекта:

| Скрипт | Что проверяет |
|--------|---------------|
| `test_no_args` | запуск без параметров |
| `test_vfs` | только `--vfs` |
| `test_script` | только `--script` |
| `test_all` | оба параметра |
| `test_bad_script` | несуществующий файл скрипта |

Запуск тестов (из корня проекта):

```
python3 -m unittest discover -s tests -v
```

## Пример использования

Запуск со стартовым скриптом `scripts/start.txt`:

```
# стартовый скрипт эмулятора
ls -l /home
cd /tmp
foo
```

Вывод:

```
[debug] vfs = None
[debug] script = scripts/start.txt
VFS$ ls -l /home
ls -l /home
VFS$ cd /tmp
cd /tmp
VFS$ foo
Unknown command
VFS$ exit
```

Запуск с несуществующим скриптом:

```
[debug] vfs = None
[debug] script = nope.txt
script not found: nope.txt
VFS$
```
